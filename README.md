# Boids

A 3D Boids simulation in Python.


Project for year 1 of master "Mathématiques et Applications" at the university of La Rochelle.


Instructions for this project were provided by our teacher Christophe Saint-Jean and are viewable here: [Guideline](./docs/guideline.pdf)


The Boids algorithm was first designed by Craig W. Reynolds, you can read the original paper here: [Flocks, Herds, and Schools: A Distributed Behavioral Model](https://dl.acm.org/doi/10.1145/37401.37406)
